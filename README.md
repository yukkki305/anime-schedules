# 每日新番更新时间表

一个**双击就能打开**的网页：按星期看日本新番这周几点播出（北京时间）。

不用装软件、不用起服务器、不用命令行——`index.html` 双击就是成品。

技术栈：纯前端 HTML + CSS + 原生 JavaScript（无框架、无构建工具、无后端）。

---

## 怎么打开

1. 下载这个仓库（`Code` → `Download ZIP`，或者 `git clone`）
2. 解压后找到 **`index.html`**
3. **双击它**，浏览器就会打开

> 第一次打开会先看到灰色的骨架卡片，等 **5–8 秒**才换成真数据——这是正常的，不是卡住了。

---

## 页面上有什么

- **顶部 7 个按钮**：周一 ~ 周日。打开时自动停在「今天」并高亮
- **右上角那颗圆按钮**：点一下切深色/浅色。点过就记住，下次打开还是这个；没点过时跟着系统的深色模式走
- **卡片**：中文标题（有的话）+ 罗马音标题 + 封面 + 北京时间 + 第几集 + 评分
- **底部一行小字**：共几部 / 是今天的还是缓存里的 / 加载中 / 加载失败

同一天内**按播出时间从早到晚**排；时间未知的排在最后。

---

## 数据是从哪来的

| 内容 | 来源 |
|---|---|
| 播出时间、集数、评分、封面 | [AniList](https://anilist.co)（免费公开接口） |
| 中文标题 | 本地文件 `data/titles-zh.js`（人工核对的对照表） |
| 封面图片 | 经 `i0.wp.com` 中转（原因见下面的「已知限制」） |

**没有后端、没有数据库、没有账号。** 你的浏览记录、看过的番，一个都不会上传——因为压根没有上传的地方。

---

## 已知限制（都是有意为之，不是坏了）

1. **首屏要等 5–8 秒**
   AniList 一次查询本身就这么慢，加上网络波动偶尔到 10 秒。所以有了灰色骨架卡片、10 秒超时、失败自动重试 2 次。
2. **中文名不全**
   中文名来自人工维护的对照表，表里没有的番**只显示罗马音**——这是故意的：宁可没有，也不显示一个错的名字。
3. **封面走第三方中转**
   AniList 自己的图片服务器在这条网络下单张要 **10–50 秒**，所以图片地址改成经 `i0.wp.com` 中转（同一个站，但快得多）。中转站是第三方免费服务，万一它挂了，封面会自动退回彩色块，页面照常能用。
4. **数据最长 30 分钟才更新**
   为了少打扰 AniList，每天的数据会缓存 30 分钟。底部小字会写「来自缓存（30 分钟内有效）」。刚播完的集数可能要等一会儿。
5. **只显示日本动画**
   AniList 里混着国漫、欧美动画，这里按「出产国 = 日本」过滤掉了。
6. **不用 ES 模块、不用框架、不用构建工具**
   全部是普通 `<script>` 标签。好处是双击就能跑；代价是没法用 `import`，文件之间靠 `window.XXX` 传对象。

## 出问题了怎么办

| 现象 | 处理 |
|---|---|
| 改了文件但页面没变 | 按 **`Ctrl + F5`** 强制刷新（`file://` 会缓存 CSS/JS） |
| 红色错误块「加载失败」 | 点里面的**重试**按钮；还不行就检查网络 |
| 一直「加载中…」转圈 | 网络到 AniList 不通，等一会儿或换个网络 |
| 某天没有卡片，显示「这天没有排播」 | 那天确实没有番剧播出，正常 |
| 页面一片空白 | 大概率是某个 JS 文件语法错了，按 `F12` 看控制台的红色报错 |

## 换季时要维护一次中文名

番剧每季都换，对照表不会自动更新。某个新番没有中文名时：

1. 打开 [yuc.wiki](https://yuc.wiki/) 当季那一页，找到它的中文名
2. 找到它在 AniList 的编号（详情页地址里 `anime/` 后面那串数字）
3. 在 `data/titles-zh.js` 里对应星期下面加一行：`编号: '中文名',`
4. `Ctrl + F5` 刷新看效果

详细步骤和注意事项写在 `data/titles-zh.js` 的文件头注释里。

## 文件都是干什么的

```
index.html              页面骨架（7 个按钮 + 卡片容器）
css/style.css           全部样式（含手机窄屏适配）
data/titles-zh.js       中文名对照表：番剧编号 → 中文名
js/time.js              UNIX 时间戳 → 北京时间 / 星期几
js/api.js               向 AniList 查某一天的排播（含超时、重试）
js/cache.js             本地缓存 30 分钟（localStorage，不可用时退内存）
js/zh.js                给卡片配中文名（先查本地表，兜底代码默认关闭）
js/ui.js                画卡片、骨架、错误块、空状态、封面懒加载
js/theme.js             深色/浅色切换（记住选择，没选过时跟系统）
js/main.js              入口：连起来、切换星期、排序、状态文字
PLAN.md                 开发记录（每个阶段做了什么、为什么）
AGENTS.md               这个项目的规矩
```

## 想改点什么

- 不想看封面：把 `js/main.js` 里的 `var SHOW_COVER = true;` 改成 `false`
- 想改缓存时长：`js/cache.js` 的 `TTL_MS`（单位毫秒，现在 `30 * 60 * 1000`）
- 想改配色：`css/style.css` 顶部的 CSS 变量（`--accent` 是主色）
- 想改深色配色：`css/style.css` 里 `:root[data-theme="dark"]` 那一块
- 想默认就深色：`index.html` 里那段 `<head>` 小脚本改成直接 `'dark'`（不推荐，跟着系统走更省心）

改完记得 `Ctrl + F5`。
